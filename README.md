The is BML. It stands for Boiwe Matrix Library. Its a 2d matrixlibray that seeks to imitate some of numpy's functionality.

Some of the functionally and documentation has been done with AI-assistance, but everything has been checked by a true, living homo sapiens sapiens (a hairless ape that lost his tail).

The library has been tried on Debian 11 and 13. FreeBSD 15 and Windows 11. MacOS have not been tested.
